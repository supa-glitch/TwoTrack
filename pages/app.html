How to format the worksheet

Start each activity with a line like Activity 1: Warm-up (or Part, Section, Station). Number each problem, and put its answer on the next line after Answer:.

Activity 1: Warm-up
Directions: Solve each equation.
1. x + 7 = 15
Answer: 8
2. 3x = 21
Answer: x = 7 | 7

Use | to list more than one accepted answer. You don’t need to list every way of writing the same answer: x = 7 and 7, 1/2 and 0.5, or 2x + 3 and 3 + 2x all count as the same. Work still counts, so 2(x + 3) is not accepted for 2x + 6.

Already have the answers at the end? Add a line Answer key and then the numbered answers (you can put Activity 2 lines in the key too).
